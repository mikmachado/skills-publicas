# Edição de vídeo

Skills para editar vídeos curtos (Reels, TikTok, Shorts) conversando com o Claude.

| Skill | O que faz | Precisa de |
| --- | --- | --- |
| [texto-em-perspectiva](texto-em-perspectiva/) | Legenda, posts e prints pintados numa parede do vídeo, em perspectiva, com você na frente. Cortes, cor e som inclusos. | macOS, ffmpeg, Python 3 |
| [posts-em-3d](posts-em-3d/) | Posts de Instagram (com vídeos tocando) e telas de música flutuando em 3D atrás de você, entrando com giro e rebote. Fundo original ou estúdio branco com reflexo. | macOS, ffmpeg, Python 3 |
